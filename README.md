# HR Analytics Project: Workforce Analysis Using Advanced Excel & SQL

## Project Overview

This project analyses a dataset of 500 employee records to understand workforce trends and support HR decision-making.

The project combines Advanced Excel for data analysis, PivotTables, KPIs, charts and dashboard creation with MySQL for structured data querying and workforce analysis.

## Tools Used

- Advanced Excel
- MySQL
- GitHub

## Key Areas of Analysis

- Workforce distribution by department
- Salary and compensation analysis
- Highest- and lowest-paid employees
- Employment status analysis
- Performance rating analysis
- Bonus distribution
- Promotion rates
- Job role analysis
- Gender distribution

## Project Structure

- **Advanced Excel** – HR dashboard, PivotTables, KPIs and visual analysis
- **SQL** – 15 MySQL queries analysing the 500 employee records
- **Screenshots** – Selected SQL query results and project visuals
